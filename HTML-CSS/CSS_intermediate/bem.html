¿Qué es BEM?

BEM viene de Block Element Modifier.
Una metodología es una forma específica de trabajar.
El uso de esta metodologia nos permite reutilizar código. También resuelve conflictos de especificidad.
BEM permite saber como nombrar las clases para simplemente al verlas saber que hacen.
Un bloque es un componente de una página que podemos reutilizar y que no depende de otro componente.
Al nombrar las clases con la metodología BEM usamos class="bloque__elemento__modificador" => class="lista__item (espacio) segunda--clase"
