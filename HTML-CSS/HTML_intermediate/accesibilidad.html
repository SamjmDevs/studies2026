En imágenes, enlaces y todo prácticamente => alt y aria-label siempre para que el lector de pantalla para ciegos aporte información auditiva sobre el contenido.
Todo debería ser navegable sin ratón, todo con la tecla tabuladora, flechas de dirección y enter.
Para ello se añade la propiedad tabindex=x, siendo x el número en orden empezando en 1
role="rol dado" => así indicamos el rol que el elemento tiene en nuestra página, mirar en la web los roles de html en accesibilidad
Abriendo consola, buscamos lighthouse (en chrome), accesibilidad (en firefox)... y el mismo navegador nos analiza la accesibilidad de nuestra web
